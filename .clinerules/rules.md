# TripMap 全局AI开发规则（强制遵守）
## 一、前置读取规则（必须按顺序执行）
1. 先读取：docs/core/00_项目总纲.md
2. 再读取：docs/core/01_架构说明.md
3. 再读取：docs/core/02_编码规范.md
4. 再读取：docs/core/03_数据库设计.md
5. 再读取：docs/core/04_接口规范.md
6. 最后读取当前任务对应的 PRD 文档

## 二、AI 行为红线（绝对禁止）
1. 禁止在未读完 core 文档前编写任何代码
2. 禁止随意修改项目架构、新增顶层包
3. 禁止超需求开发，只做当前任务范围
4. 禁止无理由删除原有代码
5. 禁止与现有代码风格、命名、结构不一致
6. 禁止随意新增字段、表、接口
7. 禁止不校验参数、不处理异常
8. 禁止不按 REST 规范写接口

## 三、编码强制要求
1. 统一使用 ApiResult<T> 返回所有接口
2. 参数错误抛出 IllegalArgumentException → 400
3. 资源不存在返回 404
4. 写方法必须加 @Transactional
5. 使用 @Slf4j 打印日志，使用 {} 占位符
6. 遵循项目分层：Controller → Service → Repository
7. 数据库字段、实体类、接口命名必须与 core 规范一致

## 四、任务执行流程
1. 读取全部核心文档 + 当前PRD
2. 扫描现有相关代码，理解现有逻辑
3. 按规范编写最小可用实现
4. 给出变更清单，不冗余、不扩散
5. 不编造不存在的类、方法、接口
