# TripMap - 旅行社交与分享平台

## 项目概述

TripMap 是一款旅行社交与分享平台，主打行程规划可视化 + 旅行分享社交功能，满足用户创建旅行计划、分享旅行见闻、与他人互动交流的需求。

**产品定位**：旅行社交与分享平台 — 不仅是规划工具，更是旅行记忆与社交的载体。

**目标用户**：旅行爱好者、行程规划者、喜欢分享旅行见闻的用户

**核心价值**：便捷的行程规划与地图可视化、轻松分享旅行计划、与志同道合的用户互动

## 现有功能（v0.1 - v0.11）

### 旅行计划管理
- 新建旅行计划（标题、开始日期、结束日期）
- 查看已有旅行计划列表
- 编辑、删除已有旅行计划
- 旅行计划公开/私密权限设置

### 每日行程规划
- 针对选定的旅行计划，按天添加行程明细
- 行程字段：具体时段、行程地点、地址、备注
- 编辑、删除单条每日行程
- 列表展示对应计划下的所有每日行程
- 行程拖拽排序
- 行程按日期分组时间轴展示（支持折叠展开）
- 行程标签分类功能

### 地图可视化联动
- 右侧地图区域，自动加载对应旅行计划下所有行程地点
- 地点点位标记展示，支持地图缩放、拖拽查看
- 行程与地图点位联动，直观对应行程和地理位置
- 地图点位与行程双向联动（点击地图点位→行程高亮滚动，点击行程→地图点位高亮居中）
- 地图路线可视化（同性行程点位按sortOrder顺序连线，不同日期路线颜色区分）
- 路线与行程双向联动高亮，支持路线显示/隐藏控制
- 地图点位信息弹窗（含快捷操作）
- 地图全屏显示模式

### 地点搜索联想
- 地址搜索自动补全功能

### 基础页面布局
- 左右分栏布局，左侧行程规划区，右侧地图展示区
- 左侧面板可拉伸（支持20%~50%范围拖拽调整）

### 技术特性
- 统一 ApiResult<T> 响应封装
- GlobalExceptionHandler 全局异常处理
- Nominatim 地理编码服务集成
- 坐标持久化缓存

## 数据库表（现有）

### v1.0 新增表
- `user` - 用户表（id, email, nickname, password, avatar_type, is_active, provider, provider_id）
- `email_verify_code` - 邮箱验证码表（id, email, code, type, expired_at）

### 现有表
- `travel_plan` - 旅行计划表（id, user_id, title, start_date, end_date, is_public）
- `daily_plan` - 每日行程表（id, plan_id, date, time, location, address, latitude, longitude, sort_order, remark, tags）
