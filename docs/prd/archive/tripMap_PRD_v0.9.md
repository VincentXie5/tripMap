## 3. 核心功能详细需求

### 3.1 旅行计划新增弹窗化

#### 功能描述
将原有的固定表单面板改为弹窗选择式交互，初始页面只显示旅行计划列表，点击新增按钮弹出创建弹窗。

#### 详细需求

**初始状态（页面加载时）：**
- 左侧只显示旅行计划列表（PlanList组件）
- 移除顶部的TravelPlanForm固定表单
- 界面更简洁，不再拥挤

**新增按钮：**
- 位置：PlanList组件左下角
- 样式：保持现有按钮风格（Element Plus风格）
- 按钮文字："新增计划"或"+"图标
- 点击后弹出"创建旅行计划"弹窗

**创建弹窗：**
- 标题：创建旅行计划
- 字段：
  - 计划名称（必填，输入框）
  - 开始日期（必填，日期选择器）
  - 结束日期（必填，日期选择器）
- 按钮：取消、确定创建
- 提交后刷新列表

**保留功能：**
- 计划列表显示（日期范围 + 计划名称）
- 计划选择点击事件（显示对应每日行程）
- 编辑计划弹窗（现有功能保留）
- 删除计划（现有功能保留）
- 导出Markdown（现有功能保留）

#### 验收标准
- 初始页面只显示旅行计划列表，无固定表单
- 左下角新增按钮样式统一、位置合理
- 点击新增按钮弹出创建弹窗
- 创建成功后自动刷新列表
- 选择计划后正常显示每日行程

---

### 3.2 每日行程新增弹窗化

#### 功能描述
将每日行程表单从固定面板改为弹窗选择式，只有在选中旅行计划后，才显示每日行程列表，左下角有点击新增按钮，点击弹出创建弹窗。

#### 详细需求

**选中计划后状态：**
- 在PlanList下方显示DailyPlanList（现有逻辑）
- 移除独立的DailyPlanForm固定面板
- 在DailyPlanList左下角显示"添加行程"按钮

**新增按钮：**
- 位置：DailyPlanList组件左下角（卡片底部）
- 样式：保持现有按钮风格（与PlanList新增按钮一致）
- 按钮文字："添加行程"或"+"图标
- 点击后弹出"添加每日行程"弹窗

**添加行程弹窗：**
- 标题：添加每日行程
- 字段：
  - 行程日期（必填，日期选择器，限制在旅行计划时间范围内）
  - 行程时间（必填，时间选择器）
  - 行程地点（必填，输入框 + 搜索联想）
  - 行程标签（可选，单选按钮组：无标签/景点/美食/住宿/交通/购物）
  - 行程备注（可选，文本域）
- 按钮：取消、确定添加
- 提交后刷新每日行程列表

**保留功能：**
- 每日行程列表显示（按日期分组、时间轴展示）
- 编辑行程弹窗（现有功能保留）
- 删除行程（现有功能保留）
- 拖拽排序（现有功能保留）
- 标签分类显示（现有功能保留）

#### 验收标准
- 选中旅行计划后显示每日行程列表
- DailyPlanList左下角有新增按钮
- 点击新增按钮弹出添加行程弹窗
- 添加成功后自动刷新列表
- 地图联动功能正常

---

### 3.3 界面布局优化

#### 功能描述
优化整体左侧面板布局，移除固定表单，改为弹窗交互，界面更清爽。

#### 布局变化

**修改前：**
```
┌─────────────────────────┐
│ TravelPlanForm (固定)   │ ← 创建计划表单（始终显示）
├─────────────────────────┤
│ PlanList (固定)         │ ← 计划列表
├─────────────────────────┤
│ DailyPlanList (条件显示) │ ← 选中计划后显示
├─────────────────────────┤
│ DailyPlanForm (条件显示) │ ← 选中计划后显示（添加行程表单）
└─────────────────────────┘
```

**修改后：**
```
┌─────────────────────────┐
│ PlanList                │ ← 只显示列表，左下角有新增按钮
├─────────────────────────┤
│ (选中计划后显示)         │
│ DailyPlanList           │ ← 选中计划后显示，左下角有添加按钮
└─────────────────────────┘
```

#### 验收标准
- 左侧面板不再拥挤
- 初始只有一个列表组件
- 弹窗交互符合用户描述
- 按钮风格保持一致

## 4. 技术实现要点

### 4.1 App.vue 变更

| 变更项 | 说明 |
|-------|------|
| 移除TravelPlanForm | 不再作为固定面板显示 |
| 保留PlanList | 初始显示，左下角需添加新增按钮 |
| 保留DailyPlanList | 选中计划后显示，左下角需添加新增按钮 |
| 移除DailyPlanForm | 不再作为固定面板，改为弹窗形式 |

### 4.2 PlanList.vue 变更

| 变更项 | 说明 |
|-------|------|
| 添加新增按钮 | 位置：卡片左下角，样式统一 |
| 新增按钮事件 | 打开"创建旅行计划"弹窗 |
| 创建弹窗 | 包含计划名称、开始日期、结束日期 |

**新增按钮示例代码：**
```vue
<template #header>
  <div class="header-wrapper">
    <span>旅行计划列表</span>
    <el-button type="primary" size="small" @click="openCreateDialog">
      + 新增计划
    </el-button>
  </div>
</template>
```

### 4.3 DailyPlanList.vue 变更

| 变更项 | 说明 |
|-------|------|
| 添加新增按钮 | 位置：卡片左下角，样式与PlanList一致 |
| 新增按钮事件 | 打开"添加每日行程"弹窗 |
| 添加行程弹窗 | 参考现有DailyPlanForm（可复用部分逻辑） |

### 4.4 新建弹窗组件

可以新建独立组件或直接在列表组件中添加：

| 组件 | 字段 | 来源 |
|-----|------|------|
| 创建旅行计划弹窗 | 计划名称、开始日期、结束日期 | 参考TravelPlanForm |
| 添加每日行程弹窗 | 日期、时间、地点、标签、备注 | 参考DailyPlanForm |
