# TripMap 架构说明

## 1. 分层架构
Controller → Service → Repository → Entity → MySQL

## 2. 包结构
- controller：接收 HTTP 请求、参数校验、返回统一封装
- service：业务逻辑、事务、校验、外部服务调用
- repository：JPA 数据读写
- entity：数据库表映射
- common：全局通用组件
- config：跨域、配置等

## 3. 核心通用组件
### 3.1 ApiResult<T>
所有接口统一返回结构：code / message / data / timestamp

### 3.2 GlobalExceptionHandler
全局异常处理：
- IllegalArgumentException → 400
- 资源不存在 → 404
- 系统异常 → 500

### 3.3 CorsConfig
允许前端 http://localhost:5173 跨域

## 4. 外部服务
### Nominatim 地理编码
- 请求间隔 1.2 秒
- 超时 10 秒
- Java 11 HttpClient 调用
