# TripMap 数据库设计
## 1. 基础配置
- MySQL 8.x
- utf8mb4
- timezone: Asia/Shanghai
- ddl-auto: update

## 2. 表结构
### travel_plan（旅行计划）
- id BIGINT PK
- title VARCHAR(255) NOT NULL
- start_date DATE
- end_date DATE

### daily_plan（每日行程）
- id BIGINT PK
- travel_plan_id BIGINT FK
- plan_date DATE
- time TIME
- location VARCHAR(255)
- latitude DECIMAL(10,7)
- longitude DECIMAL(10,7)
- sort_order INT DEFAULT 0
- remark VARCHAR(1000)
- tag INT DEFAULT 0

## 3. 枚举 tag
0=其他,1=景点,2=美食,3=住宿,4=交通,5=购物

## 4. 索引
- travel_plan: PRIMARY KEY(id)
- daily_plan: PRIMARY KEY(id)
- daily_plan: INDEX(travel_plan_id, sort_order)
