# TripMap 编码规范
## 1. 命名规范
### 1.1 Java 命名
- 类：大驼峰 PascalCase
- 方法、变量：小驼峰 camelCase
- 常量：大写下划线 UPPER_SNAKE_CASE
- 包名：全小写

### 1.2 接口命名
GET /api/资源     查询
POST /api/资源    新增
PUT /api/资源/{id} 更新
DELETE /api/资源/{id} 删除

### 1.3 数据库命名
表：snake_case 单数
字段：snake_case

## 2. 注解规范
- @RestController / @Service / @Repository
- @Transactional 写方法必加
- @Data / @Slf4j 常用
- @Entity / @Id 实体

## 3. 异常规范
- 参数错误：IllegalArgumentException → 400
- 资源不存在：RuntimeException → 404
- 系统异常：Exception → 500

## 4. 日志规范
使用 @Slf4j，占位符 {}，禁止字符串拼接

## 5. 事务规范
写操作加 @Transactional，默认 REQUIRED
