# TripMap 接口规范
## 1. 统一返回体
{
"code": 200,
"message": "操作成功",
"data": {},
"timestamp": 1713200000000
}

## 2. 状态码
200 成功
400 参数错误
401 未认证
404 资源不存在
500 服务器错误

## 3. 接口风格（RESTful）
- GET：查询
- POST：新增
- PUT：更新
- DELETE：删除

URL 格式：/api/资源名

## 4. 请求格式
- JSON 请求：@RequestBody
- 查询参数：@RequestParam
- 路径参数：@PathVariable

## 5. 日期时间格式
日期：yyyy-MM-dd
时间：HH:mm

## 6. 错误响应
统一结构，不自定义格式
