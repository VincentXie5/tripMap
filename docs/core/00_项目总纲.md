# TripMap 项目总纲

## 1. 项目概述

| 项目名称 | tripMap |
|---------|--------|
| 产品定位 | 轻量化旅行规划可视化网站 |
| 目标用户 | 个人旅行爱好者、出行规划者、自助游用户 |
| 核心价值 | 快速编排旅行日程，直观查看行程地点分布，本地运行数据私密，操作轻量化 |

## 2. 技术栈
### 后端
Spring Boot 3.2.5 + Java 17 + Spring Data JPA + MySQL 8 + Lombok + Maven

### 前端
Vue3 + Vite + Element Plus + Axios + Leaflet + OpenStreetMap

### 外部服务
- Nominatim OSM：地理编码
- OpenAI / Claude API：规划中

## 3. 项目结构

```
tripMap/
├── src/main/java/com/travel/plan/
│   ├── TripMapApplication.java      # Spring Boot启动类
│   ├── controller/                   # 控制器层
│   ├── service/                      # 服务层
│   │   └── impl/
│   ├── repository/                   # 数据仓库层
│   ├── entity/                       # 实体类
│   ├── common/                       # 通用组件
│   └── config/                       # 配置类
├── src/main/resources/
├── travel-plan-frontend/              # 前端项目
└── docs/                             # 文档目录
```

## 4. AI 开发红线规则
1. 必须先阅读本项目 core 目录下所有规范文档
2. 禁止擅自修改架构
3. 禁止新增不必要的包、类、方法
4. 禁止超需求开发
5. 必须与现有代码风格、命名、结构完全一致
6. 禁止删除原有代码
7. 必须先扫描现有实现，不要重复造轮子
8. 只做当前任务范围的事情
