## 3. 核心功能详细需求

### 3.1 地点搜索联想自动补全

#### 功能描述
在新增/编辑行程输入地点时，提供实时搜索联想建议，提升地点输入效率和准确性。

#### 交互流程
```
输入地点名称 → 实时下拉显示匹配地点建议 → 选择建议自动填充
支持模糊匹配、拼音匹配、地名关键词匹配
```

#### 详细需求
1. **触发时机**：输入3个字符后自动触发联想
2. **联想内容**：
   - 基于OpenStreetMap Nominatim地理编码接口
   - 显示地点名称、行政区划信息
   - 最多显示5条匹配结果
3. **交互特性**：
   - 键盘上下键选择，回车确认
   - 点击外部自动关闭下拉框
   - 匹配关键词高亮显示
4. **性能优化**：
   - 请求防抖: 800ms间隔 (适配Nominatim接口限流要求)
   - 本地缓存: 缓存最近50条查询结果24小时
   - 降级处理: 接口超时/失败时静默降级，不影响正常输入
   - 错误重试: 单次请求失败自动重试1次

#### 验收标准
- 输入地点时正确显示联想建议
- 选择建议后自动填充地点输入框
- 键盘操作支持正常
- 搜索结果匹配度高
- 输入过程流畅无卡顿

---

### 3.2 行程标签分类功能

#### 功能描述
支持为每个行程添加分类标签，便于行程分类管理和视觉区分。

#### 详细需求
1. **标签系统**：
   - 预定义标签：景点、美食、住宿、交通、购物、其他
   - 每种标签对应不同颜色标记
2. **行程展示**：
   - 行程列表项显示标签颜色标识
   - 地图点位标记颜色与标签对应
   - 路线颜色可根据标签区分
3. **操作流程**：
   - 新增/编辑行程时可选择标签
   - 默认无标签，可选设置
   - 标签支持批量修改
4. **兼容性**：DailyPlan实体新增tag字段，兼容历史数据

#### 验收标准
- 行程编辑表单支持标签选择
- 行程列表正确显示标签颜色标识
- 地图点位颜色与标签对应
- 历史数据无影响
- 标签修改实时生效
