### 1. 版本目标

在v0.3地图点位与行程双向联动、行程拖拽排序的基础上，增强地图可视化效果，实现同日行程点位之间的路线连线，直观展示行程路线，提升用户对行程空间分布的理解和规划效率。

### 2. 版本范围

#### 2.1 必做核心功能

**路线可视化（行程间连线）：**
- 同一天的行程点位之间用线条连接，形成路线
- 按行程的sortOrder顺序连接点位，展示行程先后顺序
- 不同日期的行程使用不同颜色的线条区分
- 路线与点位联动：点击路线可高亮显示对应日期的所有行程
- 路线样式可配置：线宽、颜色、透明度等

**交互增强：**
- 点击路线高亮显示对应日期的所有行程项
- 行程列表项点击时，对应路线同步高亮
- 路线hover效果：鼠标悬停时显示路线信息（日期、行程数量）
- 支持路线显示/隐藏切换（按日期分组控制）

#### 2.2 本版本暂不实现功能

- 用户登录、注册、权限管理
- 响应式适配移动端、平板
- 行程导出、分享功能
- 批量删除操作
- 操作历史记录与撤销功能
- 路线规划（最短路径、最优顺序）
- 多种地图样式切换

### 3. 页面结构设计

```Plain Text
首页（全屏布局）
├─ 左侧区域（固定占比40%）
│  ├─ 新建旅行计划表单
│  ├─ 旅行计划列表（日期区间 + 计划名 + [编辑] [删除]按钮）
│  └─ 选中计划的每日行程列表（时间：地点 + [编辑] [删除]按钮）
│      └─ 支持拖拽排序（拖拽手柄图标）
│      └─ 行程项点击触发路线高亮
└─ 右侧区域（固定占比60%）
   └─ Leaflet地图容器
       ├─ 行程地点标记（点位）
       ├─ 行程路线连线（Polyline）
       │   └─ 按日期分组，不同颜色区分
       └─ 点击点位/路线触发联动高亮
```

### 4. 数据模型设计

#### 4.1 旅行计划实体（TravelPlan）

保持v0.3设计不变：
- id：主键ID，Long类型，自增
- title：计划名称，字符串类型
- startDate：旅行开始日期，日期类型
- endDate：旅行结束日期，日期类型

#### 4.2 每日行程实体（DailyPlan）

保持v0.3设计不变：
- id：主键ID，Long类型，自增
- planId：关联旅行计划ID，Long类型
- planDate：行程当天日期，日期类型
- time：行程具体时段，字符串类型（如：08:00、14:00）
- location：行程地点，字符串类型（如：北京故宫、西安兵马俑）
- sortOrder：排序序号，整数类型

### 5. 核心接口清单

#### 5.1 v0.3已有接口（复用）

- POST /api/travelPlan：新建旅行计划
- GET /api/travelPlan：查询全部旅行计划列表
- PUT /api/travelPlan/{id}：更新旅行计划
- DELETE /api/travelPlan/{id}：删除旅行计划（级联删除关联行程）
- POST /api/dailyPlan：新增每日行程
- GET /api/dailyPlan/{planId}：根据计划ID查询对应全部行程
- PUT /api/dailyPlan/{id}：更新每日行程
- DELETE /api/dailyPlan/{id}：删除每日行程
- PUT /api/dailyPlan/sort/{planId}：批量更新行程排序

#### 5.2 v0.4新增接口

本版本无需新增后端接口，路线可视化完全基于前端实现，复用现有行程查询接口获取行程数据（包含经纬度坐标）。

### 6. 技术实现要点

#### 6.1 后端实现

本版本后端无需改动，复用v0.3的所有接口和数据模型。

#### 6.2 前端实现

**路线数据处理：**
- 从行程列表中提取同一天的行程数据
- 按planDate分组，每组包含该天的所有行程
- 按sortOrder排序，确保路线顺序正确
- 提取每个行程的经纬度坐标，形成坐标数组

**路线绘制：**
- 使用Leaflet L.polyline()绘制路线
- 为每个日期生成独立的Polyline图层
- 配置路线样式：颜色、线宽、透明度、虚线样式
- 使用颜色数组为不同日期分配不同颜色

**路线与点位联动：**
- 点击路线时，获取对应日期的所有行程ID
- 高亮显示左侧行程列表中对应日期的所有行程项
- 高亮显示地图上对应日期的所有点位标记
- 使用scrollIntoView滚动至第一个高亮行程项

**路线显示控制：**
- 提供按日期分组的路线显示/隐藏开关
- 默认显示所有路线
- 支持单独控制某一天路线的显示状态

**路线样式配置：**
```javascript
// 路线样式配置
const routeStyles = {
  colors: ['#409EFF', '#67C23A', '#E6A23C', '#F56C6C', '#909399'],
  weight: 3,
  opacity: 0.7,
  dashArray: '5, 10' // 虚线样式
};
```

#### 6.3 交互流程

**路线绘制流程：**
1. 用户选择旅行计划
2. 前端获取该计划下的所有行程数据
3. 按planDate分组行程数据
4. 为每个日期创建Polyline图层
5. 将Polyline添加到地图
6. 绑定点击事件，传递日期参数

**路线联动流程（点击路线→行程高亮）：**
1. 用户点击地图上的某条路线
2. 前端获取路线对应的日期
3. 清除之前的高亮状态
4. 左侧行程列表中该日期的所有行程项添加高亮样式
5. 使用scrollIntoView滚动至第一个高亮行程项
6. 地图上该日期的所有点位标记高亮显示

**路线联动流程（点击行程→路线高亮）：**
1. 用户点击左侧行程列表中的某个行程项
2. 前端获取行程对应的日期和坐标
3. 清除之前的高亮状态
4. 该日期的所有行程项添加高亮样式
5. 地图平移至该坐标并设置合适的缩放级别
6. 对应日期的路线高亮显示（改变颜色或线宽）

### 7. 交付标准

- 同一天的行程点位之间正确绘制路线连线
- 路线按sortOrder顺序连接，展示行程先后顺序
- 不同日期的行程使用不同颜色的线条区分
- 点击路线，对应日期的所有行程项正确高亮并滚动至可视区域
- 点击行程项，对应日期的路线正确高亮并地图居中
- 路线显示/隐藏切换功能正常
- 路线样式美观，线宽、颜色、透明度适中
- 路线与点位联动响应时间<200ms
- 无控制台报错，用户体验流畅

### 8. 测试要点

**路线绘制测试：**
- 单日单行程：不绘制路线（至少需要2个点位）
- 单日多行程：正确绘制路线，顺序正确
- 多日行程：不同日期使用不同颜色
- 行程拖拽排序后：路线顺序正确更新
- 删除行程后：路线正确更新

**路线联动测试：**
- 点击路线：对应日期行程高亮、滚动正确
- 点击行程：对应日期路线高亮、地图居中正确
- 连续点击不同路线：前一个高亮清除、新路线正确高亮
- 点击空白区域：所有高亮状态正确取消

**路线显示控制测试：**
- 显示/隐藏切换：功能正常
- 默认显示所有路线：正确
- 单独控制某天路线：正确

**边界情况测试：**
- 只有一个行程时：不绘制路线，无报错
- 行程坐标缺失时：跳过该点位，路线正确绘制
- 大量行程（>20条）时：性能可接受
- 长路线跨越地图边界时：显示正常

**性能测试：**
- 50个行程时路线绘制流畅度
- 路线联动响应时间<200ms
- 路线切换响应时间<100ms
