### 1. 产品基本信息

- **产品名称**：轻量化旅行规划可视化网站

- **产品定位**：本地部署、极简易用的旅行行程规划工具，主打行程列表展示+地点地图联动可视化，满足个人短途/长途旅行的行程编排、点位查看需求

- **目标用户**：个人旅行爱好者、出行规划者、自助游用户

- **核心价值**：快速编排旅行日程，直观查看行程地点分布，本地运行数据私密，操作轻量化无冗余

---

### 1.1 产品愿景（2026+）

**从"旅行规划工具"升级为"旅行社交与回忆平台"**

- 不仅是规划工具，更是旅行记忆的载体
- 连接旅行者社区，分享精彩旅程
- AI赋能，让规划更智能，让旅行更美好

---

### 2. 选定技术栈

**前后端分离架构**，贴合个人熟悉的技术体系，无额外学习成本：

- **后端**：SpringBoot 3.2.x + Maven + MySQL + Spring Data JPA + Lombok

- **前端**：Vue3 + Vite + Element Plus + Axios + Leaflet + OpenStreetMap

- **部署运行**：本地启动运行，数据本地存储，无需云端部署和外置数据库

- **认证**：JWT (JSON Web Token)

- **AI服务**：OpenAI GPT API / Claude API / 兼容OpenAI的自部署模型

### 3. 完整功能规划

#### 3.1 旅行计划管理（现有）

- 新建旅行计划，填写计划标题、出行开始日期、结束日期

- 查看已有旅行计划列表

- 编辑、删除已有旅行计划

- 旅行计划公开/私密权限设置

#### 3.2 每日行程规划（现有）

- 针对选定的旅行计划，按天添加行程明细

- 行程字段：具体时段、行程地点

- 编辑、删除单条每日行程

- 列表展示对应计划下的所有每日行程

- 行程拖拽排序

- 行程按日期分组时间轴展示（支持折叠展开）

- DailyPlan新增remark备注字段

- 行程标签分类功能

#### 3.3 地图可视化联动（现有）

- 右侧地图区域，自动加载对应旅行计划下所有行程地点

- 地点点位标记展示，支持地图缩放、拖拽查看

- 行程与地图点位联动，直观对应行程和地理位置

- 地图点位与行程双向联动（点击地图点位→行程高亮滚动，点击行程→地图点位高亮居中）

- 地图路线可视化（同性行程点位按sortOrder顺序连线，不同日期路线颜色区分）

- 路线与行程双向联动高亮，支持路线显示/隐藏控制

- 地图点位信息弹窗（含快捷操作）

- 地图全屏显示模式

#### 3.4 基础页面布局（现有）

- 整体左右分栏布局，左侧固定为行程规划区，右侧为地图展示区

- 页面适配PC端浏览器，布局铺满屏幕，操作简洁

- 左侧面板可拉伸（支持20%~50%范围拖拽调整）

#### 3.5 用户系统（新增 v1.0）

**基础功能：**
- 用户注册（用户名、邮箱、密码）
- 用户登录（JWT认证）
- 用户登出

**数据隔离：**
- 用户只能查看、编辑自己的旅行计划
- 公开/私密权限控制

**进阶功能：**
- 用户信息编辑（头像、昵称、简介）
- 修改密码
- 账户注销

#### 3.6 旅行路线分享系统（新增 v2.0）

**分享功能：**
- 生成分享链接/二维码
- 导入他人分享的旅行计划
- 路线导出为图片/PDF

**权限控制：**
- 公开模式：所有人都可以查看
- 私密模式：通过链接访问需获得授权
- 私有模式：仅自己可见

**社交功能：**
- 用户主页展示公开的旅行计划
- 收藏/点赞功能
- 评论功能

#### 3.7 AI旅行路线建议系统（新增 v3.0）

**智能推荐：**
- 基于目的地推荐必玩景点
- 根据出行天数自动生成行程框架
- 结合预算、季节、偏好（亲子/情侣/独行）生成个性化路线

**实用功能：**
- 天气/景点开放时间查询集成
- 预算估算
- 餐饮/住宿推荐

**交互方式：**
- 自然语言对话式规划（"我想去日本玩5天，帮帮我推荐路线"）
- 一键生成完整行程
- 行程微调建议

#### 3.8 多语言支持（新增 v4.0）

**功能：**
- 界面语言切换（中文/英文/日文/韩文等）
- 语言偏好记忆
- 旅行者常用目的地信息多语言显示

**技术实现：**
- 前端国际化方案（vue-i18n）
- 语言包热加载

#### 3.9 旅行日记/回忆系统（新增 v5.0）

**旅行日记：**
- 旅行结束后可以写旅行日记，关联到对应行程
- 支持上传照片，自动按日期归档到对应天
- 支持图文混排

**旅行回顾：**
- 旅行结束后自动生成"旅行回顾"页面
- 包含照片墙、精彩瞬间、统计数据（总行程天数、去过多少地方、总花费）

**时光机功能：**
- 每年同一天提醒"去年的今天你在旅行"
- 回顾往年旅行

#### 3.10 旅行清单（新增 v6.0）

**行李清单：**
- 行李清单模板：打包行李时有checklist
- 必备物品清单（证件、充电器、药品等）
- 按行程智能推荐清单（比如去海边提醒带防晒）

**预算追踪：**
- 每笔花费记录（餐饮、交通、住宿、门票等）
- 自动生成预算饼图和每日支出曲线
- 旅行结束后生成消费报告

#### 3.11 问答社区（新增 v7.0）

**问答功能：**
- 对目的地有疑问？直接提问
- 去过的人回答，形成旅行知识库
- 问答搜索

**发现功能：**
- "热门目的地"榜单（最近大家都在规划去哪）
- "灵感地图"：看看大家最近在去什么地方

#### 3.12 其他优化功能（持续迭代）

- **足迹地图**：用热力图展示去过的所有地方，统计去过多少国家/城市/总天数
- **成就系统**：旅行成就墙（首次出行、10城打卡、跨年旅行等）
- **打卡功能**：到达目的地时地理位置打卡，生成打卡海报
- **行程模板**：把好的行程保存为模板，创建新行程时一键填充
- **离线支持**：PWA支持，可离线查看已保存的旅行计划
- **数据备份与导出**：完整数据一键备份（JSON），导入/导出PDF
- **日历同步**：行程同步到Google Calendar/Apple Calendar
- **主题系统**：深色/浅色主题，季节主题皮肤

### 4. 非功能需求

- 本地启动速度快，后端、前端单独启动耗时均不超过3秒

- 接口响应流畅，数据增删改查无明显延迟

- 地图加载稳定，地点解析、点位渲染快速

- 兼容Chrome、Edge等主流PC端浏览器

- 数据本地化存储，无外网数据同步，保障隐私

- 用户数据隔离，多用户并发访问稳定

- AI服务响应时间合理（10秒内），有降级方案

- 支持高并发访问（问答社区场景）

### 5. 技术架构说明

#### 5.1 数据库设计

**现有表（已存在）：**
- `travel_plan` - 旅行计划表（id, title, start_date, end_date）
- `daily_plan` - 每日行程表（id, plan_id, date, time, location, address, latitude, longitude, sort_order, remark, tags）

**新增表：**
- `sys_user` - 用户表（id, username, email, password_hash, nickname, avatar, created_at, updated_at）
- `travel_diary` - 旅行日记（id, plan_id, user_id, date, content, photos, created_at）
- `travel_expense` - 旅行花费（id, plan_id, user_id, category, amount, description, date）
- `checklist_template` - 清单模板（id, name, items, is_default）
- `question` - 问答问题（id, user_id, destination, title, content, created_at）
- `answer` - 问答回答（id, question_id, user_id, content, created_at）
- `public_plan` - 公开计划（plan_id, user_id, views, likes）

**表结构变更：**
- `travel_plan` 表新增字段：user_id（所属用户）、is_public（是否公开）、is_private（是否私有）
- `daily_plan` 表无需变更
- `travel_diary` 表关联 travel_plan 表（通过 plan_id）
- `travel_expense` 表关联 travel_plan 表（通过 plan_id）
- `public_plan` 表关联 travel_plan 表（通过 plan_id）
- `question` 表新增 field: destination（目的地）
- `answer` 表关联 question 表（通过 question_id）
- `checklist_template` 表支持用户自定义模板
- `sys_user` 表支持用户基本信息存储

#### 5.2 认证方案

- JWT Token认证
- Token有效期：7天（可配置）
- 刷新Token机制

#### 5.3 AI服务接入

- 支持OpenAI API兼容接口
- 支持Claude API
- 支持自部署开源模型（如LLama）
- 抽象AI Provider接口，便于切换

#### 5.4 国际化和本地化

- 前端：vue-i18n
- 支持语言：zh-CN, en-US, ja-JP, ko-KR（逐步扩展）
- 语言资源文件外置，支持热更新
