## 3. 核心功能详细需求

### 3.1 地图点位信息弹窗

#### 功能描述
点击地图上的行程点位时，弹出信息卡片展示行程完整信息，提供快捷操作入口，完善地图交互体验。

#### 交互流程
```
点击地图点位 → 弹窗在点位旁弹出 → 展示行程详情 → 支持快捷操作
点击地图空白/ESC键 → 弹窗自动关闭
```

#### 详细需求
1. **弹窗内容**：
   - 行程时间（时:分格式）
   - 地点名称（大号字体突出显示）
   - 备注信息（灰色小字，存在时显示）
2. **快捷操作**：
   - 「编辑」按钮：直接打开该行程的编辑表单
   - 「删除」按钮：删除该行程点位
   - 「定位」按钮：将该点居中放大显示
3. **交互特性**：
   - 弹窗打开时，对应行程列表项自动高亮
   - 点击地图空白区域或按ESC键自动关闭弹窗
   - 弹窗位置智能避让屏幕边界
4. **视觉设计**：
   - 白色卡片圆角阴影样式
   - 指针指向对应地图点位
   - 动画过渡效果

#### 验收标准
- 点击任意地图点位正确弹出信息弹窗
- 弹窗内容与行程信息完全一致
- 所有快捷操作按钮功能正常
- 弹窗自动关闭逻辑正常
- 列表与弹窗双向联动高亮正常

---

### 3.2 地图全屏模式

#### 功能描述
地图区域支持一键切换全屏显示，提升长行程、多地点时的地图浏览体验。

#### 详细需求
1. **控件位置**：地图右上角新增全屏切换按钮
2. **全屏特性**：
   - 全屏模式下地图铺满整个浏览器窗口
   - 所有地图功能（标记、路线、缩放、拖拽）完全正常工作
   - 全屏状态下保持原有的所有交互逻辑
3. **退出方式**：
   - 点击全屏按钮退出
   - 按ESC键退出全屏
4. **兼容性**：
   - 支持Chrome、Edge浏览器原生全屏API
   - 全屏模式下页面无滚动条、无留白

#### 验收标准
- 全屏切换按钮清晰可见
- 进入/退出全屏动画流畅
- 全屏模式下所有地图功能正常工作
- 键盘ESC退出功能正常
- 切换全屏时地图状态无抖动、无重置
