## 3. 核心功能详细需求

### 3.1 行程时间轴展示优化

#### 功能描述
将原平铺的行程列表优化为**按日期分组的时间轴展示形式**，提升行程可读性与视觉层次感。

#### 页面效果
```
📅 2026年4月10日 周五
┌──────────────────────────────────┐
│ 08:00  北京首都机场             │
│ 12:00  西安咸阳机场             │
│ 14:30  西安城墙                 │
│ 18:00  回民街美食               │
└──────────────────────────────────┘

📅 2026年4月11日 周六
┌──────────────────────────────────┐
│ 09:00  秦始皇兵马俑博物馆       │
│ 13:00  华清宫                   │
│ 17:00  大雁塔                   │
└──────────────────────────────────┘
```

#### 详细需求
1. **日期分组**：行程按planDate自动分组，每个日期为独立分组
2. **折叠/展开**：每个日期分组支持折叠/展开切换，默认全部展开
3. **时间轴视觉**：
   - 左侧显示垂直时间轴线
   - 每个行程项对应时间点位置
   - 时间与地点左右对齐
4. **日期标题**：显示日期、星期几、行程数量
5. **交互保持**：原有点击高亮、拖拽排序、编辑删除功能全部保留

#### 验收标准
- 行程正确按日期分组展示
- 折叠/展开功能正常
- 时间轴视觉效果清晰美观
- 所有原有交互功能不受影响
- 拖拽排序在分组内正常工作

---

### 3.2 行程备注字段

#### 功能描述
为每日行程新增备注字段，支持用户记录行程详细说明、注意事项、交通信息等补充内容。

#### 数据模型变更
**DailyPlan实体新增字段：**
| 字段名 | 类型 | 说明 |
|--------|------|------|
| remark | String | 行程备注，最大长度1000字符，允许为空 |

#### 功能需求
1. **表单支持**：新增/编辑行程表单新增备注输入框（textarea多行输入）
2. **列表展示**：行程列表项下方显示备注内容，文字较小，灰色显示
3. **接口支持**：所有DailyPlan接口同步支持remark字段的读写
4. **兼容性**：历史无备注数据正常显示，不报错

#### 验收标准
- 新增行程时可填写备注
- 编辑行程时可修改备注
- 备注内容正确保存到数据库
- 列表中备注正常展示
- 无备注时不显示空占位

---

### 3.3 旅行计划Markdown导出功能

#### 功能描述
支持将当前选中的旅行计划导出为标准Markdown格式文本，方便用户复制、分享、保存到笔记软件。

#### 导出格式示例
```markdown
# 西安三日游

⏰ 出行时间：2026-04-10 至 2026-04-12

## 2026-04-10 周五
- 08:00 北京首都机场
- 12:00 西安咸阳机场
- 14:30 西安城墙
- 18:00 回民街美食

## 2026-04-11 周六
- 09:00 秦始皇兵马俑博物馆
- 13:00 华清宫
- 17:00 大雁塔

## 2026-04-12 周日
- 10:00 陕西历史博物馆
- 16:00 西安北站返程

---
*由 tripMap 旅行规划系统自动生成*
```

#### 功能需求
1. **导出按钮**：旅行计划操作区新增「导出Markdown」按钮
2. **一键复制**：导出弹窗中显示生成的Markdown内容，提供一键复制功能
3. **导出内容**：包含计划标题、出行日期、按日期分组的所有行程、备注信息
4. **纯前端实现**：导出功能完全在前端实现，无需后端接口

#### 验收标准
- 生成的Markdown格式正确、排版美观
- 包含全部行程信息与备注内容
- 一键复制功能正常工作
- 导出内容可直接粘贴到笔记软件正常显示
- 大量行程导出无性能问题
